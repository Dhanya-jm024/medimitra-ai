# Devfolio Submission Text — MediMitra AI

## Project Name
MediMitra AI

## Tagline
Your AI Health Companion — Speaks Your Language, Understands Your Needs

## Problem Statement
70% of rural populations face severe healthcare access barriers due to a 1:10,000 doctor-to-patient ratio, language illiteracy, delayed disease diagnosis, and zero internet connectivity in remote areas.

## Solution Overview
MediMitra AI is a production-grade Next.js 14 & FastAPI web app that brings multimodal AI healthcare into rural homes. It allows users to describe symptoms orally in 10+ Indic languages, scan medicine strips with Gemini 2.0 Vision, locate nearby emergency trauma centers with GPS SOS, and manage offline health records.

## Tech Stack
- Next.js 14 App Router, TypeScript, Tailwind CSS
- Google Gemini 2.0 Flash & Gemini Vision AI
- Web Speech API (STT / TTS)
- openFDA API & Google Maps API
- FastAPI Python Backend & Medical RAG
- next-pwa for offline service worker support

## Key Accomplishments
- Implemented full voice STT & TTS flow in 5 major languages (EN, HI, KN, TA, TE)
- Sub-2-second AI diagnostic triage turnaround
- High contrast WCAG AAA accessibility compliance with elderly font scaling
- Built-in PWA offline cache for zero-network rural zones
