# SLIDE 5: ⚡ Simple as 1 - 2 - 3
### From Symptom to Triage Solution in Seconds

1. **🎙️ SPEAK**: Tap one microphone and speak naturally (e.g. *"मुझे 2 दिनों से तेज बुखार है"*).
2. **🧠 ANALYZE**: Google Gemini 2.0 processes symptoms with probability & 93%+ confidence score.
3. **📋 UNDERSTAND**: View condition summary, home remedies, and emergency warnings.
4. **🎯 ACT**: Hear diagnostic readout out loud in spoken Hindi, Kannada, Tamil, or Telugu.

## ---
# SLIDE 7: 🛠️ Tech Stack & Architecture

- **Frontend**: Next.js 14 (App Router) • React 18 • TypeScript 5.0 • Tailwind CSS • Framer Motion • Recharts
- **AI Engine**: Google Gemini 2.0 Flash & Gemini Vision SDK • Web Speech API
- **Backend API**: FastAPI (Python 3.12) • Python RAG Medical Knowledge Engine
- **Database & Auth**: Supabase PostgreSQL • Row Level Security (RLS)
- **Telemetry**: OpenStreetMap Overpass API • Nominatim Reverse Geocoding • openFDA Drug API • Twilio SMS
- **Hosting**: Vercel Serverless Edge • GitHub Actions CI/CD
