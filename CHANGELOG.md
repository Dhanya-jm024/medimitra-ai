## [1.0.0] - 2026-07-28

### Added
- 🎙️ Multilingual Voice-First Symptom Checker supporting English, Hindi, Kannada, Tamil, and Telugu with Web Speech STT/TTS audio readouts.
- 💊 Multimodal Gemini 2.0 Vision Pill & Prescription OCR Scanner with openFDA drug interaction safety checks.
- 🩺 Skin & Wound Visual Triage AI with first-aid steps.
- 🚨 Global High-Precision Satellite GPS Emergency SOS Locator with OpenStreetMap Overpass API and Haversine proximity calculations.
- 📱 Progressive Web App (PWA) Service Worker support for 100% offline rural operation.
- ♿ WCAG AAA High Contrast mode and dynamic font scaling (**A- / A / A / A+**).
- 🎬 Automated AI Pitch Video Presenter Studio (`/demo-video`).
- ⚡ Next.js 14 App Router frontend & FastAPI Python microservice.
